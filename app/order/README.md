# Order Service - 订单服务

## 服务说明

订单服务负责处理订单相关的业务逻辑，包括订单创建、订单查询、购物车管理等功能。

## 需要实现的功能

### 1. 订单管理
- 创建订单（需要调用库存服务扣减库存）
- 订单列表查询（分页）
- 订单详情查询
- 更新订单状态

### 2. 购物车管理
- 添加商品到购物车
- 购物车列表查询
- 更新购物车商品数量
- 删除购物车商品

## 架构说明

订单服务涉及复杂的业务流程和分布式事务：
- **服务调用**: 需要调用商品服务、库存服务
- **分布式事务**: 订单创建需要保证数据一致性（DTM）
- **状态管理**: 订单状态流转（待支付、已支付、已发货、已完成、已取消）

## 使用的技术栈

- gRPC - RPC 通信
- GORM - ORM 框架
- DTM - 分布式事务管理
- Consul - 服务注册与发现
- Redis - 缓存
