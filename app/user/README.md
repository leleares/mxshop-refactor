# User Service - 用户服务

## 服务说明

用户服务负责处理用户相关的业务逻辑，包括用户注册、登录、信息管理等功能。

## 需要实现的功能

### 1. 用户管理
- 用户列表查询（分页）
- 根据 ID 查询用户
- 根据手机号查询用户
- 创建用户
- 更新用户信息

### 2. 密码管理
- 密码加密存储
- 密码验证

## 目录结构

```
app/user/
├── client/          # 客户端封装（保留）
├── srv/             # 服务端实现
│   ├── config/      # 配置定义（保留）
│   ├── app.go       # 服务启动入口（保留）
│   ├── rpc.go       # gRPC 服务实现（保留）
│   ├── controller/  # 控制器层（需实现）
│   ├── service/     # 业务逻辑层（需实现）
│   ├── data/        # 数据访问层（需实现）
│   └── wire.go      # 依赖注入（需实现）
└── README.md        # 本文件
```

## 架构说明

采用三层架构：
- **Controller 层**: 处理 gRPC 请求，参数验证
- **Service 层**: 核心业务逻辑
- **Data 层**: 数据库操作和数据转换

## 使用的技术栈

- gRPC - RPC 通信
- GORM - ORM 框架
- Wire - 依赖注入
- Consul - 服务注册与发现
