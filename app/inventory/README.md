# Inventory Service - 库存服务

## 服务说明

库存服务负责处理商品库存相关的业务逻辑，包括库存查询、库存扣减、库存归还等功能。

## 需要实现的功能

### 1. 库存管理
- 设置库存
- 查询库存详情
- 扣减库存（支持分布式事务）
- 归还库存（订单取消/退货）

### 2. 库存锁定
- 预扣库存（下单时锁定）
- 释放锁定库存

## 架构说明

库存服务是高并发场景的核心服务，需要特别注意：
- **并发控制**: 使用 Redis 分布式锁或数据库乐观锁
- **事务管理**: 支持分布式事务（DTM）
- **性能优化**: 缓存热点商品库存

## 使用的技术栈

- gRPC - RPC 通信
- GORM - ORM 框架
- Redis - 分布式锁
- DTM - 分布式事务管理
- Consul - 服务注册与发现
