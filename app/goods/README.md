# Goods Service - 商品服务

## 服务说明

商品服务负责处理商品相关的业务逻辑，包括商品管理、分类管理、品牌管理、轮播图管理等功能。

## 需要实现的功能

### 1. 商品管理
- 商品列表查询（分页、搜索、过滤）
- 商品详情查询
- 创建商品
- 更新商品信息
- 删除商品
- 批量查询商品

### 2. 分类管理
- 分类列表查询
- 分类详情
- 创建分类
- 更新分类
- 删除分类
- 获取子分类

### 3. 品牌管理
- 品牌列表查询
- 品牌详情
- 创建品牌
- 更新品牌
- 删除品牌

### 4. 品牌分类关联
- 获取分类品牌列表
- 创建分类品牌关联
- 删除分类品牌关联

### 5. 轮播图管理
- 轮播图列表
- 创建轮播图
- 更新轮播图
- 删除轮播图

## 目录结构

```
app/goods/
├── client/          # 客户端封装（保留）
├── srv/             # 服务端实现
│   ├── config/      # 配置定义（保留）
│   ├── app.go       # 服务启动入口（保留）
│   ├── rpc.go       # gRPC 服务实现（保留）
│   └── internal/    # 内部实现（需实现）
│       ├── controller/  # 控制器层
│       ├── service/     # 业务逻辑层
│       ├── data/        # 数据访问层（MySQL）
│       ├── data_search/ # 搜索层（Elasticsearch）
│       └── domain/      # 领域模型
│           ├── do/      # 数据对象
│           └── dto/     # 数据传输对象
└── README.md        # 本文件
```

## 架构说明

采用 DDD（领域驱动设计）分层架构：
- **Controller 层**: 处理 gRPC 请求
- **Service 层**: 业务逻辑
- **Data 层**: MySQL 数据持久化
- **Data_Search 层**: Elasticsearch 搜索
- **Domain 层**: 领域模型定义

## 使用的技术栈

- gRPC - RPC 通信
- GORM - ORM 框架
- Elasticsearch - 商品搜索
- Consul - 服务注册与发现
